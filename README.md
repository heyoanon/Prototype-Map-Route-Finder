# Prototype-Map-Route-Finder
Prototype Shortest Route Emergency Map Finder

- A Smart Emergency Response & Route Optimization System that uses graph-based data structures and various networking algorithms to find the shortest path for emergency assistance and respone.

- To run in other algorithms, just change the python code in (Bellmans - Ford) folder. (Example: using A* algorithm instead of Bellman - Ford)

- Changes are also implemented as of this moment.
